## O que é o Ladesa?

O Laboratório de Desenvolvimento de Softwares Acadêmicos (Ladesa) é um projeto de **pesquisa e soberania tecnológica** do Instituto Federal de Rondônia — Campus Ji-Paraná.

Seu objetivo é desenvolver uma solução **gratuita e open-source** para substituir o sistema comercial usado atualmente para geração de horários acadêmicos no IFRO.

O Ladesa é composto por dois sistemas integrados: o **SISGHA** (Sistema de Geração de Horário Acadêmico) e o **SISGEA** (Sistema de Gestão de Ambientes Acadêmicos). Leia mais sobre eles na página [Sistemas do Ladesa](./sistemas).
