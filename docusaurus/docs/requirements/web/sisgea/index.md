# SISGEA — Sistema de Gestão de Ambientes Acadêmicos

O SISGEA gerencia blocos e ambientes físicos (salas, laboratórios, auditórios) do campus. Integrado ao SISGHA para validar disponibilidade de sala antes de confirmar alocações na grade.

## Escopo

| Funcionalidade | Descrição |
|---|---|
| **Ambientes** | CRUD de ambientes com foto, nome, código, capacidade, tipo, bloco |
| **Blocos** | CRUD de blocos (edifícios) vinculados a campus |
| **Reservas** | Grid semanal de reservas por ambiente, com criação e consulta |

## Navegação (Sidebar)

| Item | Descrição |
|---|---|
| Reservas | Home — grid semanal de reservas |
| Ambientes | Listagem e gestão de ambientes |
| Blocos | Listagem e gestão de blocos |
| Configurações | Configurações do sistema |
| Sair | Logout |
