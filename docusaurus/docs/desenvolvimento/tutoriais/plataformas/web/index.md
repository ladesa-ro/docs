# Desenvolvimento Web

Esta seção reúne tutoriais sobre as tecnologias de desenvolvimento web utilizadas no projeto Ladesa.

## Stack web do Ladesa

O frontend web do Ladesa é construído com:

- **[Vue.js](https://vuejs.org/)** — framework JavaScript progressivo para construção de interfaces;
- **[Nuxt 4](https://nuxt.com/)** — framework full-stack baseado em Vue que fornece SSR, roteamento automático e estrutura de projeto;
- **[Tailwind CSS v4](https://tailwindcss.com/)** — framework CSS utilitário para estilização rápida e consistente.

## Tutoriais disponíveis

Explore os subtópicos desta seção para aprender sobre cada tecnologia individualmente:

- **Vue** — fundamentos do Vue.js e seu ecossistema;
- **Nuxt** — estrutura de diretórios, páginas, rotas e composables;
- **Vuetify** — biblioteca de componentes Material Design para Vue.
